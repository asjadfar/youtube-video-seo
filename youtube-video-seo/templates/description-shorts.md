2 lines, one line about what the Short teaches, the channel link,

description with `scripts/check_seo.py`.

## Checklist for this description

- [ ] Main keyword in the first 2 lines
- [ ] Promise in the first 2 lines — what the viewer will learn
- [ ] One line about what is actually in the Short — nothing more
- [ ] No timestamps (Shorts do not need them)
- [ ] Links only as the owner approved — no link that was not given
- [ ] 2–3 hashtags maximum, at the end
- [ ] At least 100 characters
- [ ] No keyword stuffing, no claim the Short does not deliver

## Shorts vs long-form — what is different

| | Long-form | Shorts |
|---|---|---|
| Description length | 200–400 characters is a good length | Short — keyword, promise, one line, links, hashtags |
| Timestamps / chapters | Yes, checked against the real video | No |
| Thumbnail | Custom 1280x720 thumbnail uploaded | Best frame chosen in YouTube Studio; first 1–2 seconds must show the subject |
| End screens / cards | Yes — last 20 seconds, 1–2 cards | No — closing line points to the next Short instead |
| Title | Full keyword phrase, under 60 characters | Shorter and punchier, keyword first |
